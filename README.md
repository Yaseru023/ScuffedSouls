# ScuffedSouls

A Minecraft Forge 1.20.1 mod adding custom gameplay mechanics, player classes, buildup effects, and Souls-inspired systems.

## Features

* Player classes
* Custom buildup system
* Soul Anchor XP storage
* XP loss on death
* Item durability loss on death
* Custom status effects
* Client/server synchronization
* Dimension-specific effects

## Requirements

* Minecraft 1.20.1
* Minecraft Forge 47.4.0
* Java 17+

## Development

Clone the repository and import it into IntelliJ IDEA as a Gradle project.

Run the client with:

```bash
./gradlew runClient
```

On Windows:

```powershell
.\gradlew runClient
```
